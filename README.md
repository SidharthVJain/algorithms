# Cube Algorithms

A static, minimal website for entering personal OLL, PLL and F2L algorithms.

## Run locally

Open `index.html` in a browser. No build step or network connection is required.

## Included

- OLL: case names and probabilities from the supplied `oll-algorithms.pdf`.
- PLL: case names and probabilities from the supplied `pll-algorithms.pdf`.
- F2L: the four slot positions and section organization from the supplied `f2l-algorithms-different-slot-positions.pdf`.
- Cube diagrams copied from the uploaded `algorithms.zip` archive.
- Three editable formula fields per entry: Recommended, Alternate 1, Alternate 2.
- Browser-local persistence via `localStorage`.
- Search and Empty / Started filters.

The algorithm fields are intentionally blank.
